# Repository Instructions

This repository is a public-safe bootstrap pack for Toan's personal website.

## Rules

- Read `content-source/README.md` and `content-source/MANIFEST.md` before writing website copy.
- Treat `content-source/approved/` as the factual source of truth.
- Do not reconstruct career facts or project facts from memory.
- Use only quantitative claims approved by `content-source/approved/proof-register.md`.
- Preserve attribution for project-specific proof.
- Keep Aitbase Camera separate from Aitbase Omnichannel.
- Never expose private CV or Marketing OS information.
- Never edit provenance to hide the original source.
- Do not add website dependencies or an application scaffold in the bootstrap commit.
- Do not deploy or merge automatically.
- Symphony work must happen on issue branches and end in draft pull requests.
- The initial direct-to-main bootstrap commit is a one-time exception.
- Visual inspiration must not copy reference-site code, branding, copy, or exact layouts.
- Do not modify the Marketing OS repository from here.

## Working Method

- Check `content-source/MANIFEST.md` before using any approved file.
- Prefer curated public extracts over direct copies when a source mixes public and private material.
- Keep claim wording aligned with the proof register and its qualification notes.
- Discover package-manager and validation commands from repository files after the Astro application has been scaffolded.
